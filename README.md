# Hi, I'm Haven 👋

**Research Assistant** at the [Center for Environmental Intelligence (CEI), VinUniversity](https://cei.vinuni.edu.vn/) · Vietnam

I build software end to end, including AI agent platforms, full-stack web apps, native macOS tools, speech-processing pipelines, and ESP32 hardware.
I like systems you can verify: written-down decisions, automated quality gates, and status reports that say what was actually tested.

> Most of my work lives in private repositories. I'm happy to walk through the code and design on request.

## 🔭 What I'm building

| Area | Project | What it shows |
|---|---|---|
| **AI agents** | Multi-tenant platform for AI agencies to configure, publish, and deliver operational agents to their clients | TypeScript monorepo (Turborepo), NestJS + Fastify API, Postgres + pgvector knowledge bases, isolated per-user agent workspaces on S3-compatible storage, encrypted per-user credentials, MCP tool integration, Playwright + Vitest |
| **AI assistant** | *AI Chief of Staff*: a personal assistant that turns commitments, calendar events, and activity signals into sourced briefings and next-action recommendations | Swift 6 native macOS core, a privacy-first activity sensor that never records screen contents, AI commentary kept separate from sourced facts, research into local Vietnamese–English speech recognition |
| **Full-stack web** | [toanhoccoban.vn](https://toanhoccoban.vn): a live site with video lessons and a document library for a math teacher | Next.js, React, Tailwind, Neon Postgres, Auth.js, Google Drive API, Vercel with CI on every push |
| **Productivity app** | Deep-work task tracker with quotas, focus sessions, streaks, and reminders | Next.js, Drizzle ORM, Neon Postgres, Claude API, web push, Google Calendar and GitHub integration, scheduled jobs on Vercel |
| **Speech & audio ML** | Pipeline that turns a Vietnamese song recording into a playable karaoke chart | Vocal separation, whisper.cpp, wav2vec2 (ONNX INT8) CTC forced alignment, pYIN pitch tracking, memory-bounded CPU-only runs |
| **Embedded / IoT** | *DigitCode*: an escape-room puzzle game that runs on both a desktop app and a physical panel | Qt 6 / C++ / QML app synced in real time with ESP32 firmware over a custom WebSocket/JSON protocol |

## 💼 What I bring

- **Product delivery**: I take ideas from a domain model to production deployment, including CI, scheduled jobs, and documentation that clearly states what has and hasn't been verified.
- **Applied AI**: LLM integration, agent tooling (MCP), retrieval with vector search, and on-device speech models tuned for limited hardware.
- **Backend & data**: Typed APIs, PostgreSQL schema design and migrations, multi-tenant access control, and secrets handling.
- **Cross-platform**: Web, native macOS (Swift), desktop (Qt/C++), and microcontrollers (ESP32).
- **Engineering practice**: Architecture decision records, domain glossaries, test gates, reproducible results (pinned models, checksums), and AI-assisted development workflows.
